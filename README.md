# AI bust: profit destroyed and delayed across the chip stack

A single-page bear-case map of the semiconductor profit pool. For each sub-sector it sets today's operating profit beside the profit that would be destroyed or delayed in the trough year, under two scenarios (full bust and financing-led), with five-year CDS spreads for CoreWeave, SoftBank, Oracle and Nvidia.

All figures are estimates in US$ billions, as of November 2026. Not investment advice.

Also available in Traditional Chinese (`tc/`, 繁體中文) and Simplified Chinese (`sc/`, 简体中文).

The page is self-contained: open `index.html` or view it on GitHub Pages.
